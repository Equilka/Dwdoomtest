
# Data directory

The directory contains the necessary data for the bot to work.              
All data in this directory is generated in DataRepository class.

For the file installer and player to work properly, please place the [yt-dlp](https://github.com/yt-dlp/yt-dlp/releases) and [ffmpeg](https://www.ffmpeg.org/) here.

## yt-dlp issues

If you have problems with authorization in yt-dlp, you can place the cookies.txt here.   
[How to extract cookies?](https://www.reddit.com/r/youtubedl/wiki/cookies/)
